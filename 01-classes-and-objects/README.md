This module introduces the fundamental concepts of **Object-Oriented Programming (OOP)** using C++. It focuses on creating classes, objects, member functions, and solving real-world problems using object-oriented design.

---

## 📂 Programs Included

1. Student Class
2. Employee Class
3. Car Class
4. Book Class
5. Bank Account Class
6. Mobile Class
7. Product Class
8. Rectangle Class
9. Static Data Member
10. Object as Function Argument
11. Array of Objects

---

## 📖 Concepts Covered

- Class and Object
- Data Members
- Member Functions
- Access Specifiers
- Object Creation
- Object Initialization
- Static Data Members
- Passing Objects to Functions
- Array of Objects
- Real-world Class Design

---

## 🎯 Learning Outcomes

After completing this module, you will be able to:

- Create and use classes and objects.
- Define member functions.
- Understand object creation and initialization.
- Work with arrays of objects.
- Pass objects as function arguments.
- Implement simple real-world applications using OOP.
