This module demonstrates the concept of **Polymorphism**, one of the four fundamental principles of **Object-Oriented Programming (OOP)** in C++. It covers both **Compile-Time Polymorphism** and **Runtime Polymorphism** using practical examples.

---

## 📂 Programs Included

1. Function Overloading
2. Operator Overloading
3. Function Overriding using Virtual Function
4. Virtual Function
5. Pure Virtual Function
6. Abstract Class
7. Runtime Polymorphism
8. Compile-Time Polymorphism
9. Virtual Destructor

---

## 📖 Concepts Covered

- Compile-Time Polymorphism
- Runtime Polymorphism
- Function Overloading
- Operator Overloading
- Function Overriding
- Virtual Functions
- Pure Virtual Functions
- Abstract Classes
- Dynamic Binding (Late Binding)
- Static Binding (Early Binding)
- Base Class Pointer
- Virtual Destructor

---

## 🎯 Learning Outcomes

After completing this module, you will be able to:

- Understand the concept of polymorphism in C++.
- Differentiate between compile-time and runtime polymorphism.
- Implement function and operator overloading.
- Override functions using virtual functions.
- Work with abstract classes and pure virtual functions.
- Use base class pointers for runtime polymorphism.
- Understand the importance of virtual destructors.
- Build flexible and reusable object-oriented programs.
