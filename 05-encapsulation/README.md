This module demonstrates the concept of **Encapsulation**, one of the four fundamental principles of **Object-Oriented Programming (OOP)** in C++. It focuses on protecting object data using private members and providing controlled access through public member functions.

## 💡 Key Takeaways

- Encapsulation combines **data** and **methods** into a single unit (class).
- Private members prevent unauthorized access.
- Getter and Setter methods provide controlled access to data.
- Input validation improves program reliability.
- Encapsulation promotes secure, reusable, and maintainable code.
