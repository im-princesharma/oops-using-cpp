This module demonstrates different types of constructors and destructors in C++. It explains object initialization, object destruction, constructor chaining, dynamic memory allocation, and initialization lists.

---

## 📂 Programs Included

1. Default Constructor
2. Parameterized Constructor
3. Copy Constructor
4. Constructor Overloading
5. Destructor
6. Dynamic Constructor
7. Constructor Initialization List
8. Array of Objects with Constructor
9. Constructor and Destructor Execution Order

---

## 📖 Concepts Covered

- Default Constructor
- Parameterized Constructor
- Copy Constructor
- Constructor Overloading
- Destructor
- Dynamic Memory Allocation
- new and delete
- Constructor Initialization List
- Constructor Chaining
- Object Lifetime

---

## 🎯 Learning Outcomes

After completing this module, you will be able to:

- Initialize objects using different constructors.
- Create copies of objects.
- Allocate dynamic memory safely.
- Understand constructor and destructor execution.
- Manage object lifetime efficiently.
