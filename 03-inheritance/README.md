This module demonstrates different types of inheritance in C++. It explains code reusability, constructor/destructor behavior, function overriding, protected members, and virtual base classes.

---

## 📂 Programs Included

1. Single Inheritance
2. Multilevel Inheritance
3. Multiple Inheritance
4. Hierarchical Inheritance
5. Hybrid Inheritance
6. Constructor in Inheritance
7. Destructor in Inheritance
8. Protected Access Specifier
9. Function Overriding
10. Virtual Base Class

- Single Inheritance
- Multilevel Inheritance
- Multiple Inheritance

- Hybrid Inheritance
- Constructor Chaining

- Protected Members
- Function Overriding
- Diamond Problem
- Virtual Base Classes

---

## 🎯 Learning Outcomes

After completing this module, you will be able to:

- Reuse code using inheritance.
- Implement different inheritance models.
- Understand constructor and destructor execution order.
- Override inherited functions.
- Resolve ambiguity using virtual base classes.
